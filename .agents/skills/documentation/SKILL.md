# Documentation Skill

## Objective
Produce accurate, user-friendly, and maintainable project documentation reflecting the actual implementation.

## Process
1. Inspect entire codebase: Read `models/`, `services/`, `routes/`, `database/`, and `tests/`.
2. Generate or update:
   - `README.md`: System overview, setup guide, architecture highlights, test commands.
   - `docs/api.md`: API specifications, request/response formats, status codes.
   - `docs/deployment.md`: Environment setup, production deployment, database migration.
   - `docs/user-guide.md`: Step-by-step user guide for all 4 roles.
   - `docs/presentation-outline.md`: Slide outline for project presentation.
   - `docs/ai-evaluation.md`: Critical evaluation of AI agent strengths, limitations, and human gate effectiveness.
   - `docs/mcp-integration.md`: Model Context Protocol integration pattern.

## Rules
- Do not document features that have not been implemented.
- Keep technical details consistent with code.
- Maintain readable Markdown formatting and clear tables.
